# Практика 4. Создание услуг

`POST /services` проверяет запрос по модели Pydantic `ServiceCreate` и сохраняет услугу в SQLite. При успешной записи API возвращает `201 Created` и данные услуги с её `id`.

## Запуск

Выполните в папке проекта на Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [Swagger UI](http://127.0.0.1:8000/docs) или выполните запросы из `requests.http`. При запуске приложение открывает `data/salon.sqlite3` и создаёт отсутствующие таблицы.

## Проверка запроса

- `categoryId` — целочисленный идентификатор существующей категории. Неизвестная категория возвращает `404`.
- `title` и `desc` — строки длиной от 1 до 100 символов после удаления пробелов по краям.
- `duration` — целое число от 30 до 180 минут включительно.
- `price` — конечное число больше нуля.

При ошибке валидации API возвращает `422`. В `requests.http` приведены три запроса из задания. В приложенной базе уже есть услуга «Наращивание ресниц» в категории 3, добавленная первым запросом. Каждый повтор успешного запроса создаёт отдельную запись. Сохранённые услуги учитываются в `servicesCount` при чтении категорий.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
