# Задание 4 — Асинхронный JavaScript и React

Данные приходят через fetch от имитационного API Vite. Сегодня запрашивается отдельно, затем на его основании выбирается месяц и начальный день. Для календаря и слотов раздельно реализованы загрузка, ошибка и данные. Ошибки HTTP проверяются через response.ok; есть повтор запроса. При смене дня старый запрос отменяется AbortController, флаг active и сверка date не дают применить неактуальный ответ. Дата валидируется сервером, прошлые дни отклоняются. Сервер работает в dev и preview. Предусмотрены воспроизводимые режимы ошибок через .env.local, без дополнительных кнопок в пользовательском интерфейсе.

## Запуск

Требуется Node.js 22.12+ (или 20.19+).
Из этой папки выполните:
```sh
npm install
npm run dev
```
Откройте адрес из терминала (по умолчанию http://127.0.0.1:3000).
Для точного воспроизведения дерева зависимостей можно использовать pnpm:
```sh
pnpm install --frozen-lockfile
pnpm dev
```
Проверка и сборка:
```sh
npm test
npm run build
npm run preview
```

## API и воспроизводимые сценарии

- `GET /api/booking/today` → `{day, month, year}`.
- `GET /api/slots?day=31&month=9&year=2026` → `{date, slots}`.
- `month` от 0 до 11. Слот — `{time, available}`.
- Задержка по умолчанию 600 мс. 29 число любого месяца возвращает пустой список. На чётные и нечётные дни разные наборы слотов.
- Проверка даты возвращает 400 для несуществующих и прошлых дней, 405 для неверного метода, 404 для неизвестного адреса API.

Для проверки ошибки создайте `.env.local` рядом с package.json:
```dotenv
KONTUR_API_FAIL=slots
KONTUR_API_DELAY=1000
```
Перезапустите `npm run dev`. Сначала загрузится календарь, затем появится сообщение об ошибке расписания и кнопка повтора. Значение `today` проверяет ошибку календаря, `all` — оба запроса. Удалите строку `KONTUR_API_FAIL` и перезапустите сервер для обычной работы. Значение `KONTUR_API_DELAY=0` отключает задержку.

Vite preview также подключает имитационный API. При размещении только папки dist на статическом хостинге для API потребуется отдельный сервер.
