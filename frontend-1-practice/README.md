# Задание 1 — HTML и CSS

Семантическая страница «Выбор даты и времени»: header, nav, main, section, aside, footer. Календарь октября 2026, выбранное 31 число, сегодняшнее 24 число, слоты 12:00, 16:00, 17:00 и занятый 18:00. Сводка услуги, мастер, длительность, цена, нижняя панель, контакты. CSS вынесен отдельно, использованы Grid и Flexbox, hover и focus-visible. Есть адаптивные варианты для планшета и телефона. Это статическая практика: переключение дат и времени реализовано в следующей версии.

## Запуск

Откройте index.html двойным кликом. Установка зависимостей не нужна.
