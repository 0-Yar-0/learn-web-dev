# Занятие 1 — запись клиента и рабочее время

Оба задания реализованы в `salon.py`, демонстрация — `demo.py`. Нужен Python 3.10+, внешних зависимостей нет.

```powershell
python demo.py
python -m unittest discover -s tests -v
```

## Задание 1

`Appoinment` — dataclass с полями `id`, `client_name`, `master_id`, `service_id`, `time`. Написание имени класса сохранено из документа. В `appointments` хранятся объекты, поэтому доступны `appointment.client_name` и `appointment.time`.

`create_appointment(client_name, master_id, service_id, time)` находит мастера и услугу, проверяет обязательные поля и создаёт объект. Пустое или состоящее из пробелов имя, неизвестный ID, незаполненное поле и неверный формат времени возвращают `None`. Список при этом не меняется. Сам класс также не позволяет создать объект с незаполненными полями.

## Задание 2

Время начала должно находиться между **08:00 и 20:00 включительно**. Разрешён формат `HH:MM`, например `08:00`; `8:00`, `24:00` и `12:60` отклоняются. Длительность услуг в условиях не задана, поэтому ограничение проверяет время начала. Дата визита и дополнительные правила занятости в этой практике не моделируются.

## Примеры из условия

После двух корректных записей программа выводит:
```text
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00
```

Сценарии ошибки запускаются независимо на пустом списке. Для пустого имени и времени 00:00 результат — `None`, количество записей — 0. В исходном примере опечатка `len(appointment)`; проверять следует `len(appointments)`. Если до отказа были успешные записи, их количество сохраняется, а не становится нулём.

Справочники мастеров и услуг учебные, хранятся в памяти. Модуль не создаёт записи при импорте.
